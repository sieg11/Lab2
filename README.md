Лабораторная работа: Перемножение матриц 4096×4096

Результаты

Вариант Время Производительность
1. Наивный (ijk)  ~3600 с  ~38 MFlops 
2. cblas_sgemm (MKL)  0.571 с  240 719 MFlops 
3. AVX2 + упаковка + OpenMP  0.605 с  227 204 MFlops 

Сложность: c = 2·n³ = 2·4096³ ≈ 1.374·10¹¹ FLop  
Производительность: p = c / t · 10⁻⁶ MFlops  
Вариант 3 достигает 60-70% от BLAS


Описание вариантов

Вариант 1 — Наивный алгоритм — прямая реализация формулы C[i][j] = Σ A[i][k]·B[k][j]. Очень медленно

Вариант 2 — cblas_sgemm (Intel MKL) — стандартная функция BLAS.

Вариант 3 — Оптимизированный:

Упаковка панелей A и B в непрерывные буферы — устраняет промахи кэша

AVX2 микроядро 6×16 с FMA инструкциями — 96 операций за итерацию

OpenMP — параллелизм по блокам строк на все ядра

Запуск

В Intel oneAPI Command Prompt:

cd путь\к\папке

chcp 65001

cl /O2 /arch:AVX2 /DUSE_MKL /openmp lab2.c /I"%MKLROOT%\include" /link mkl_rt.lib /LIBPATH:"%MKLROOT%\lib\intel64"

lab2.exe

Вариант 1 не работает по умолчанию, #define SKIP_NAIVE в коде можно закомментировать чтобы он работал
